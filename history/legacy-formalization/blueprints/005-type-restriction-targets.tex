\begin{theorem}[RegionTypeClassification, superseded ID: TYPE-001]
For a canonical stabilizer projection state on a countable region, the
represented region von Neumann algebra has one of the following types,
according to its internal fixed rank \(p\) and defect rank \(r\):
\[
\begin{array}{c|c|c}
p<\infty & r<\infty & \text{finite type I}\\
p=\infty & r<\infty & \text{type } I_\infty\\
p<\infty & r=\infty & \text{hyperfinite type } II_1\\
p=\infty & r=\infty & \text{type } II_\infty.
\end{array}
\]
In particular no canonical projection state in this class produces a type III
region algebra.
